## 4. Переклад 136 статей (локально, ~136 викликів API)

```
cd ayurveda-content
npm run content:uk:dry           # одна стаття, нічого не пише
node tools/translate-to-uk.js --limit 3
npm run content:uk               # решта
npm run content:uk:status
```

Рядки записуються зі статусом `draft`. Якщо після повторної спроби в тексті лишається формулювання, схоже на health claim, рядок отримує статус `needs_review`. Після вичитки опублікуйте:

```sql
update public.foods_uk set status = 'published' where status = 'draft';
```

Далі перезберіть сайт у Netlify: Deploys → Trigger deploy.

## Як це працює

- **Мова.** Застосунок визначає мову за браузером (`uk*` → українська). Перемкнути можна в шапці (`УК`/`EN`), у ⚙︎ («Language · Мова») або на сторінці входу. Вибір запамʼятовується. Параметр `?lang=uk|en` у посиланні має пріоритет, тому кнопка з `/uk/food/` відкриває застосунок українською.
- **ШІ.** `analyse` пише весь текст для читача українською. Технічні поля (tastes, virya, verdict) і `foodName` лишаються англійською: застосунок і довідник працюють саме з ними. Українська назва страви приходить в окремому полі `foodNameUk`. `guide` відповідає українською, навіть якщо питання поставлено російською.
- **Health claims.** У `analyse.js` і `guide.js` додано українські патерни. Звичайне `\b` у JavaScript не працює з кирилицею, тому використано Unicode-межу слова. Тести: `node patches/test_i18n_v5_3_0.js` → 160/160. Прогін `analyse` з підміненою моделлю: «Імбир покращує травлення» вирізається.

## Перевірка після деплою

1. Підвал сторінки входу: **v5.3.0**, посилання «English · Українська».
2. Відкрийте `https://ayurveda-food.com/?lang=uk`: інтерфейс має бути українською.
3. Відкрийте `https://ayurveda-food.com/i18n/uk.js`: має повертатися JS, а не сторінка 404.
4. Проаналізуйте одну страву українською: поради мають бути українською, назва — «Рис басматі».
5. `https://ayurveda-food.com/uk/food/ghee/`: до публікації перекладів — 302 на `/food/ghee/`, після — українська стаття.

## Що лишилося англійською

- Старі записи щоденника: це збережений текст попередніх аналізів.
- OG-картинки `/og/*` і JSON-LD-властивості (`Rasa (taste)` тощо).
- Сторінка оплати Stripe Checkout. Чи підтримує вона українську, я не перевіряв.
- Назва книжки Васанта Лада (свідомо) та службові повідомлення для розробника (Google OAuth, ключ API).
